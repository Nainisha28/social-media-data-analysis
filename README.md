# Social Media - Data Analysis

## About the Project

This project uses Python to parse and analyze social media profile data related to the coding and technology community in Bangalore.

The raw data contains information such as:

- Username
- Number of posts
- Number of followers
- Number of following
- Page type
- Name
- Bio

## Objective

The main objective of this project is to convert raw text data into structured data and perform basic analysis on the profiles.

The project analyzes:

- Profile with the maximum number of posts
- Profile with the maximum number of followers
- Profile following the highest number of accounts
- Number of different page categories

## Technologies Used

- Python
- Jupyter Notebook
- JSON
- Basic Python data structures

## Project Workflow

1. Read the raw profile data.
2. Split the raw data into individual profile records.
3. Parse each record using Python.
4. Convert follower, following and post counts into numerical values.
5. Store the cleaned data in structured format.
6. Save the processed data as JSON.
7. Perform basic analysis on the dataset.

## Files

- `coders-of-blr.ipynb` - Jupyter Notebook containing the Python code and analysis.
- `finaldata.txt` - Raw profile data used for the project.
- `data.json` - Structured JSON data generated from the raw data.
